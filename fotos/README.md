# Fotos reais dos serviços

Suba as fotos em uma pasta com o nome do serviço (o mesmo "slug" da página):

```
fotos/desentupimento-de-pia/foto.jpg
fotos/limpa-fossa/foto.jpg
fotos/hidrojateamento/foto.jpg
```

A primeira foto de cada pasta vira a foto do serviço no site (otimizada no build).
A pasta `fotos/geral/` é usada no topo da página inicial e na seção "Por que a Dutra".
